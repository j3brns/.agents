# Causeway — Mental Model

One page. If you remember nothing else, remember the pictures.

## The reframe: the wall is a ramp

Most enterprises run two worlds with a wall between them:

```
  SANDBOX                    │ ║ │                    PRODUCTION
  trust nothing,             │ ║ │              permit nothing
  permit everything          │ ║ │           except the attested
  (disposable, fast)         │ ║ │            (governed, slow)
                          the wall: no door
```

Causeway replaces the wall with a **ramp** — four stages where governance rises exactly
as fast as the work matures, and never faster:

```
  S0 Explore → S1 Incubate → S2 Harden → S3 Pre-prod
  permit all     ↑ evidence accumulates ↑     permit only
  trust all                                    the attested
        └────── the same repo, gaining standing ──────┘
```

## The three things that move (and the one that doesn't)

| Moves with you | Stays behind |
|---|---|
| **The repo** — agent bundle + IaC + evidence. The promotable truth. | **The account** — disposable, nuked and recycled every lease. Holds no state by design. |
| **The certificate** — a stamped passport: which stage, what evidence, who signed. | |
| **The lineage** — every artefact knows which golden template it came from. | |

> Accounts are the rental car you return empty. The repo is the luggage you carry.
> Causeway makes sure nothing of value is left in the car when it's crushed.

## How you cross: self-assert, and get spot-checked

You do **not** queue at a gate for every step. The default is the **inner loop** — build,
push, repeat, at sandbox speed. Crossing a stage line, you **self-assert** readiness.

Standing at the line is an **adjudicator** — an agent, not a person — reading your change
for two things: **risk** (security, blast radius, data) and **cost** (spend trajectory,
commercial exposure). Customs, automated:

```
   your change ──► adjudicator ──► within envelope?
                                     │
                  ┌──────────────────┴───────────────────┐
              YES │ self-assertion stands                 │ NO — risk/cost elevated
                  │ (verified in parallel, revoked        │
                  │  if evidence later fails)             │ held for TWO PAIRS OF EYES
                  ▼                                        ▼
            keep moving, fast                       second human signs
                                                    (security or budget owner)
```

**Trust, but verify — and revoke.** Low-stakes crossings trust your assertion and verify
behind you; if the evidence fails, the certificate is revoked and the unit freezes. Only
adjudicated elevation, and the one hard boundary (S2→S3, into the governed estate), pull
in a second human. Ceremony is rationed to where it earns its cost.

## The loop that improves the system itself

Spec → interview → decision → ADR → spec → spike → repeat. The platform refines the same
way the workloads do: evidence-first, decisions recorded, nothing trusted that isn't
verifiable. The docs you're reading are the system of record, regenerated by the same
merge that changes the design.

## Say it in one breath

> **A sandbox where nothing is trusted and everything is permitted, graduating — one
> self-asserted, evidence-stamped step at a time, with an agent watching for risk and
> cost — into an estate where nothing is permitted except what's attested.**
