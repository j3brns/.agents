The one idea

Progressive conformance.

Permissive on day one. Conformance you accrue, not a gate you queue at. Each push generates signed evidence; promotion is a one-line merge request.

No standing committee. No ticket to start. The system collects the proof as a by-product of the work.

Day one, for a developer

One file. Three actions. Minutes to a live AI sandbox.

  • 1
    Start — file a “new experiment” issue. A repo and an AWS account arrive pre-wired. No keys, no ticket.
  • 2
    Build — agentcore dev & git push. You never leave the inner loop.
  • 3
    Promote — open a merge request that changes one line: stage: explore → incubate.

Why this is safe, not just fast

Trust, but verify — and revoke.

Self-assert

You move now. The assertion buys motion.

Verify in parallel

The verifier still runs on every transition — asynchronously.

Revoke on failure

Evidence fails → the certificate is revoked, the unit freezes.

The durable state is always evidence, not opinion. Self-assertion only changes when the check falls — never whether proof is required.

Every step issues a certificate. Published.

A signed, human-readable passport per unit: which stage, what evidence, which approvers, which verifying release. A passport, not a logfile.

Standing is visible on the docs site — a regulator or auditor reads a unit’s attestation trail without access to a single pipeline, and without a meeting.
